# Reference archive

`source-registry.json` is the machine-readable source of truth. Local copies
exist only where redistribution is clear enough and pinning the exact artifact
materially improves reproducibility. `scripts/check_references.py` verifies
topic coverage and every local SHA-256 digest.

The archive does not mirror living framework documentation or copyrighted
books. Follow the canonical URL in the registry and record the retrieval date
when an article is revised.
