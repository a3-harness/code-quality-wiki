# Contributing knowledge

## Content standard

Every dimension page should contain purpose, criteria, review questions,
warning signals and failure modes, strong evidence, and related dimensions.
Process pages should define when the process applies, its inputs, decisions,
outputs, and common misuse.

## Contribution rules

- Prefer causal mechanisms over lists of fashionable smells.
- Distinguish universal principles from language, framework, or domain guidance.
- Add examples that include both a real concern and a near miss or counterexample.
- Cite primary standards, official documentation, or original research for
  claims that depend on an external authority.
- State limitations and the scope in which advice applies.
- Link related concepts instead of copying the same guidance across files.
- Keep `data/taxonomy.json` synchronized when dimensions or criteria change.

## Review checklist

Before merging knowledge changes, verify terminology, internal links, taxonomy
alignment, concrete failure modes, evidence fit, and absence of unsupported
absolute claims. A practitioner should be able to use the page to ask better
questions without treating it as an automatic verdict.
